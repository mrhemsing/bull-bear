# Asset Production Plan

## Objective

Produce the canonical visual library for Bull Bear:

- 20 still hero images
- 60 looped animations (3 per state)

## Production order

### Phase 1 — still approvals
1. Generate all 20 still images.
2. Review them as a full set, not one by one in isolation.
3. Verify smooth progression from state 01 to state 20.
4. Lock the approved still for each state.

### Phase 2 — animation batch 1
1. Use the approved still as the anchor image.
2. Generate Variation A for all 20 states.
3. Review for consistency and loop quality.

### Phase 3 — animation batch 2
1. Generate Variation B for all 20 states.
2. Review atmosphere motion and loopability.

### Phase 4 — animation batch 3
1. Generate Variation C for all 20 states.
2. Review creature tension and identity preservation.

## Review checklist

For every asset ask:
- Is it clearly the same creature?
- Is the state readable relative to adjacent states?
- Are the eye color, horns, claws, hoof emphasis, and posture aligned to the intended band?
- Does the Wall Street setting remain recognizable?
- Does the animation feel subtle and premium rather than chaotic?

## Naming convention

### State stills
- `state-01/still.png`
- `state-02/still.png`
- ...
- `state-20/still.png`

### Loop variants
- `state-01/loop-a.mp4`
- `state-01/loop-b.mp4`
- `state-01/loop-c.mp4`

## Launch strategy

If needed, the product can launch in phases:

### Launch A
- 20 stills only

### Launch B
- 20 stills + 20 A-variant loops

### Launch C
- full 20 stills + 60 total loops
